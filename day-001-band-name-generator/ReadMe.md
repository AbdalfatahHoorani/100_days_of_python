# Day 1: Band Name Generator 🎸

This is the first project from the "100 Days of Code: The Complete Python Pro Bootcamp". It is a simple command-line application that generates a creative band name by combining user inputs.

## 📝 Description
The Band Name Generator asks the user for the name of the city they grew up in and the name of a pet.
It then combines these two strings to suggest a unique band name.

## ✨ Features
- **Interactive Prompts:** Uses the `input()` function to gather data from the user.
- **String Concatenation:** Combines multiple strings and variables into a single output message.
- **Dynamic Output:** Generates a different result every time based on user input.

## 💡 What I Learned
- Working with the `print()` function to display text.
- Using the `input()` function to capture user data.
- Storing information in **variables** for later use.
- Manipulating strings and using **concatenation** (the `+` operator) to join text together.

## 🚀 How to Run
1. Ensure you have Python installed on your machine.
2. Save the code as `BandNameGenerator.py`.
3. Run the script using your terminal or IDE:
   ```bash
   python BandNameGenerator.py
