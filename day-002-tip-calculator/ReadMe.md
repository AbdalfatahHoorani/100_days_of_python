# Day 2: Tip Calculator 💸

This is the second project from the "100 Days of Code: The Complete Python Pro Bootcamp". It is a mathematical tool designed to help groups of people calculate the exact amount each person owes when splitting a bill, inclusive of a percentage-based tip.

## 📝 Description
The program automates the math behind dining out or sharing costs. It takes the total bill, adds a user-defined tip percentage, and then divides the final amount equally among the participants.

## ✨ Features
- **User Input Handling:** Collects numerical data (bill, tip, and number of people) using the `input()` function.
- **Data Type Conversion:** Converts input strings into `float` and `int` to perform mathematical calculations.
- **Mathematical Logic:** Uses arithmetic operators to calculate the final total per person.

## 💡 What I Learned
- Working with different **Data Types** (Integers and Floats).
- **Type Casting:** Changing data from one type to another (e.g., converting a string input into a float).
- **Mathematical Operators:** Using `+`, `*`, and `/` to solve real-world problems.
- **Order of Operations:** Using parentheses to ensure the math is calculated in the correct sequence.
